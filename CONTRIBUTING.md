# Contributing

Thanks for helping improve the General Knowledge Game.

## Get started

1. Follow the installation steps in [README.md](README.md).
2. Create a branch for your change.
3. Keep changes focused and describe the user-facing effect in your pull request.

## Pull requests

- Explain the problem and the proposed change.
- Include screenshots for visible UI changes when practical.
- Note any database or configuration changes.
- Do not include credentials, personal data, or generated files.

## Code style

Follow the existing PHP, JavaScript, and CSS conventions. Use prepared statements for database queries and escape user-provided output when rendering HTML.
